# Python Basic Projects (Python 基础与实用小工具集)

> 🐍 **Python 实用小工具与数据分析实战项目集**，涵盖基础语法、文件持久化、网络 API 解析、中文分词统计与 Pandas 数据分析。全库代码采用**语义化纯英文命名**，配备**教学级注释与开箱即用运行示例**。

---

## ⚡ 极速开始 (环境与运行)

本项目在根目录统一使用 [`uv`](https://github.com/astral-sh/uv) 管理虚拟环境与依赖，无需手动创建 venv：

```bash
# 1. 一键安装并同步所有依赖
uv sync

# 2. 运行任意案例小工具（示例：中文文本分词与可视化）
uv run python 04_text-analyzer/main.py
```
