# 获取最新汇率工具

## 项目说明
这是一个使用 Python 编写的实时汇率查询与换算工具。
程序启动后自动获取最新汇率数据，并支持任意货币之间的金额换算。

## 当前功能
- 接收最新的汇率信息
- 先自动算一遍1美元等于多少人民币/欧元/日元
- 随后可以自己手动输入想要的汇率信息

## 运行方式
```
uv run main.py
```

## 运行示例
```
正在获取最新汇率...
数据日期：2026-04-24

1 USD = 6.84 CNY（人民币）
1 USD = 0.855 EUR（欧元）
1 USD = 159.62 JPY（日元）

输入原始货币（如 CNY），输入 q 退出：CNY
输入目标货币（如 USD）：USD
输入金额：10000
10000.0 CNY = 1461.99 USD

输入原始货币（如 CNY），输入 q 退出：q
程序结束
```
